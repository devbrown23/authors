# LSAT Gauntlet

An untimed LSAT drilling game in a single HTML file. Open `index.html` in a browser to play.

- 85 original practice questions: Logical Reasoning, Reading Comprehension, terminology and if-then translation
- XP, ranks, streaks and a rematch queue for missed questions
- Playbook, flashcards and memory hooks
- Study plan, registration tracker and countdown clock

Progress is saved in the browser on the device you use. The questions are original practice material; use official LSAT questions from LSAC's LawHub for timed sections and full practice tests.
